## 4. 書くときの注意（ご自身用）

- 「自主制作」であることは必ず明記する（「導入実績」「〇社で利用」とは書かない）
- 削減時間・精度などの数値は、実際に測った場合のみ書く。それ以外は「〜を目指せます」「想定される効果」とする
- 会社サイト（grom-a.co.jp）の実績は、自分が担当したと確認できるもの以外は個人の実績として書かない
- 提案文の「対応範囲」は、実際に一人で対応できる内容だけにする
